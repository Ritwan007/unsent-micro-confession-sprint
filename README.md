## What it does

`main.py` (Python standard library only, no input, no network) writes one
two-part micro-confession — a `To:` line naming who the message was meant for,
and the unsent message itself, one line written exactly as it was typed — to
`/output/entry.txt`.

The confession was chosen from 14 candidates by a full pairwise round-robin
against the judge's published criteria (specificity and honesty, a felt reason
it stayed in drafts, To:/message coupling, reads as typed and never sent).
The champion won its round-robin 13–0. See the candidate list and the full
round-robin table in the build notes kept alongside the entry.

## Run

```sh
python3 main.py
cat /output/entry.txt
```
